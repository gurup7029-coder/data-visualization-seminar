🌍 Topic 02 • Section 2.1

Geographic Data with Basemap

One common type of visualization in data science is that of geographic data. Matplotlib's main tool for this type of visualization is the Basemap toolkit, which lives under the mpl_toolkits namespace. It provides a Matplotlib axes that understands spherical coordinates and allows us to easily over-plot data on the map.

Python Code — Orthographic Globe 
import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.basemap import Basemap

plt.figure(figsize=(8, 8))
m = Basemap(projection='ortho',
            resolution=None,
            lat_0=50, lon_0=-100)
m.bluemarble(scale=0.5)

💡 Real-World Example & Industry Application
🌐 Real-World Example: NASA Earth Observatory Blue Marble satellite composites visualizing continental vegetation and cloud cover patterns.
🏢 Where It Is Used: Space agency planetary monitoring (NASA/ESA), international climate tracking, and aerospace mission orbital path visualizers.
🌍 Topic 02 • Section 2.2

Map Backgrounds & Grid Lines

We'll use an etopo image (which shows topographical features both on land and under the ocean) as the map background. The draw_map() helper draws shaded relief with parallels and meridians.

Python Code — draw_map helper 
from itertools import chain

fig = plt.figure(figsize=(8, 8))
m = Basemap(projection='lcc', resolution=None,
            width=8E6, height=8E6,
            lat_0=45, lon_0=-100)
m.etopo(scale=0.5, alpha=0.5)

def draw_map(m, scale=0.2):
    m.shadedrelief(scale=scale)
    lats = m.drawparallels(np.linspace(-90, 90, 13))
    lons = m.drawmeridians(np.linspace(-180, 180, 13))
    lat_lines = chain(*(tup[1][0] for tup in lats.items()))
    lon_lines = chain(*(tup[1][0] for tup in lons.items()))
    all_lines = chain(lat_lines, lon_lines)
    for line in all_lines:
        line.set(linestyle='-', alpha=0.3, color='r')

🖼️ Shaded Relief with Grid Lines

💡 Real-World Example & Industry Application
🌐 Real-World Example: Nautical navigation charts displaying seafloor bathymetry trenches and global latitude/longitude grid intersections.
🏢 Where It Is Used: International maritime shipping (IMO), oceanographic research vessels, and submarine cable route surveys.
🌍 Topic 02 • Cylindrical

Cylindrical Projections

The simplest of map projections are cylindrical projections, in which lines of constant latitude and longitude are mapped to horizontal and vertical lines, respectively. This type of mapping represents equatorial regions quite well, but results in extreme distortions near the poles.

📖 Cylindrical Projection — Key Points

  • Plate Carrée: projection='cyl' — simplest cylindrical projection with equidistant latitude lines.
  • Mercator: projection='merc' — preserves angles (conformal) but distorts area near poles.
  • Cylindrical Equal-Area: projection='cea' — preserves area but distorts shapes.
  • The additional arguments specify llcrnrlat/lon (lower-left corner) and urcrnrlat/lon (upper-right corner) in degrees.
Python Code — Cylindrical 
fig = plt.figure(figsize=(8, 6), edgecolor='w')
m = Basemap(projection='cyl', resolution=None,
            llcrnrlat=-90, urcrnrlat=90,
            llcrnrlon=-180, urcrnrlon=180)
draw_map(m)
💡 Real-World Example & Industry Application
🌐 Real-World Example: Web mapping tiles (Web Mercator) powering Google Maps, OpenStreetMap, and equatorial marine charts.
🏢 Where It Is Used: Urban ride-sharing logistics (Uber, Ola), commercial fleet telematics, and equatorial forestry surveys.
🌍 Topic 02 • Pseudo-Cylindrical

Pseudo-Cylindrical Projections

Pseudo-cylindrical projections relax the requirement that meridians (lines of constant longitude) remain vertical; this can give better properties near the poles. The Mollweide projection is one common example, in which all meridians are elliptical arcs. It is constructed so as to preserve area across the map.

Python Code — Mollweide 
fig = plt.figure(figsize=(8, 6), edgecolor='w')
m = Basemap(projection='moll', resolution=None,
            lat_0=0, lon_0=0)
draw_map(m)

📖 Pseudo-Cylindrical — Key Points

  • Mollweide: projection='moll' — equal-area projection; preserves area but distorts shape near poles.
  • Sinusoidal: projection='sinu' — another equal-area pseudo-cylindrical projection.
  • Robinson: projection='robin' — compromise projection balancing area and shape distortion.
  • Extra arguments: lat_0 (central latitude) and lon_0 (central longitude) for the desired map.
💡 Real-World Example & Industry Application
🌐 Real-World Example: IPCC global climate change reports plotting worldwide greenhouse gas emissions on equal-area projection surfaces.
🏢 Where It Is Used: United Nations climate studies, global biodiversity conservation mapping, and world population density choropleth charts.
🌍 Topic 02 • Perspective

Perspective Projections

Perspective projections are constructed using a particular choice of perspective point, similar to if you photographed the Earth from a particular point in space. One common example is the orthographic projection (projection='ortho'), which shows one side of the globe as seen from a viewer at a very long distance. Thus, it can show only half the globe at a time.

📖 Perspective — Key Points

  • Orthographic: projection='ortho' — view from infinite distance; shows half the globe at a time.
  • Gnomonic: projection='gnom' — projects from the center of the Earth; great circles appear as straight lines.
  • Stereographic: projection='stere' — conformal projection useful for small portions of the map.
  • These are often the most useful for showing small portions of the map.
Python Code — Orthographic 
fig = plt.figure(figsize=(8, 8))
m = Basemap(projection='ortho', resolution=None,
            lat_0=50, lon_0=0)
draw_map(m)
💡 Real-World Example & Industry Application
🌐 Real-World Example: Geostationary meteorological satellites (GOES/Meteosat) transmitting hemispheric real-time cyclone storm views.
🏢 Where It Is Used: National weather forecast broadcasts, defense surveillance command centers, and space probe tracking.
🌍 Topic 02 • Conic

Conic Projections

A conic projection projects the map onto a single cone, which is then unrolled. This can lead to very good local properties, but regions far from the focus point of the cone may become very distorted. One example is the Lambert conformal conic projection (projection='lcc'), which projects the map onto a cone with two standard parallels (lat_1 and lat_2).

Python Code — Lambert Conformal Conic 
fig = plt.figure(figsize=(8, 8))
m = Basemap(projection='lcc', resolution=None,
            lon_0=0, lat_0=50,
            lat_1=45, lat_2=55,
            width=1.6E7, height=1.2E7)
draw_map(m)

📖 Conic — Key Points

  • Lambert Conformal: projection='lcc' — preserves angles; scale accurate near standard parallels.
  • Equidistant Conic: projection='eqdc' — preserves distance along meridians.
  • Albers Equal-Area: projection='aea' — preserves area across the map.
  • lat_1, lat_2 specify the two standard parallels where scale is most accurate.
  • width, height specify the map extent in projected meters.
💡 Real-World Example & Industry Application
🌐 Real-World Example: Aeronautical VFR navigation sectional charts for mid-latitude transcontinental flights across continents.
🏢 Where It Is Used: Civil Aviation Authorities (FAA/DGCA), national weather radar composite maps, and regional geological surveys.
🌍 Topic 02 • Map Background

Drawing a Map Background

The Basemap package contains a range of useful functions for drawing borders of physical features like continents, oceans, lakes, and rivers, as well as political boundaries such as countries and US states.

🗺️ Physical Boundaries & Bodies of Water

  • drawcoastlines() — Draw continental coast lines
  • drawlsmask() — Draw a mask between land and sea
  • drawmapboundary() — Draw map boundary, fill color for oceans
  • drawrivers() — Draw rivers on the map
  • fillcontinents() — Fill continents with a given color

🏛️ Political Boundaries

  • drawcountries() — Draw country boundaries
  • drawstates() — Draw US state boundaries
  • drawcounties() — Draw US county boundaries

📐 Map Features

  • drawgreatcircle() — Draw a great circle between two points
  • drawparallels() — Draw lines of constant latitude
  • drawmeridians() — Draw lines of constant longitude
  • drawmapscale() — Draw a linear scale on the map

🌐 Whole-Globe Images

  • bluemarble() — Project NASA's blue marble image
  • shadedrelief() — Project a shaded relief image
  • etopo() — Draw an etopo relief image
  • warpimage() — Project a user-provided image
💡 Real-World Example & Industry Application
🌐 Real-World Example: Disaster relief maps layering river flood inundation boundaries on top of county and municipal administrative borders.
🏢 Where It Is Used: Emergency management agencies (NDMA/FEMA), coastal zone municipal planning, and international boundary treaty mapping.
🌍 Topic 02 • Data Overlay

Plotting Data on Maps

The Basemap toolkit provides the ability to over-plot a variety of data onto a map background. There are many map-specific functions available as methods of the Basemap instance.

🖱️ Interactive World Map — Projection Switcher

📖 Map-Specific Plot Methods

  • contour()/contourf() — Draw contour lines or filled contours
  • imshow() — Draw an image
  • pcolor()/pcolormesh() — Pseudocolor plot for irregular/regular meshes
  • plot() — Draw lines and/or markers
  • scatter() — Draw points with markers
  • quiver() — Draw vectors
  • barbs() — Draw wind barbs
  • drawgreatcircle() — Draw a great circle
💡 Real-World Example & Industry Application
🌐 Real-World Example: Overlaying live atmospheric hurricane wind vectors (quivers) and temperature isobars over geographic map layers.
🏢 Where It Is Used: National hurricane centers (NOAA/IMD), commercial airline flight dispatch, and oceanic current energy harvesting.
🌍 Topic 02 • Great Circles

Great Circle Flight Arcs

m.drawgreatcircle() draws the shortest path between two points on the Earth's surface — the great circle arc. This is how airlines plot flight routes on flat maps.

Python Code — Great Circle Flight Arcs 
# New York (40.71, -74.00) -> London (51.50, -0.12)
m.drawgreatcircle(-74.00, 40.71, -0.12, 51.50,
                  linewidth=2, color='red')

# Tokyo (35.67, 139.65) -> San Francisco (37.77, -122.41)
m.drawgreatcircle(139.65, 35.67, -122.41, 37.77,
                  linewidth=2, color='gold')

🖼️ Great Circle Map Output

⚖️ Basemap vs Cartopy — Key Differences

  • Basemap: Transforms data points manually before plotting with Matplotlib functions.
  • Cartopy: Uses standard Matplotlib transform=ccrs.PlateCarree() arguments directly inside ax.plot().
  • Status: Basemap is deprecated — Cartopy is the recommended successor for new projects.
💡 Real-World Example & Industry Application
🌐 Real-World Example: Intercontinental flight routes (e.g. New York to London) curving northward to follow shortest spherical Great Circle geodesics.
🏢 Where It Is Used: Commercial airline fuel optimization flight computers, international avionics routing, and long-range ballistic trajectory plotting.
